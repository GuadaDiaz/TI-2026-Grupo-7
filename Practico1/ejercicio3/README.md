# Ejercicio 3 — Entropía y redundancia de archivos (TXT vs. ZIP)

Calcula la entropía de Shannon y la redundancia (respecto del máximo de 8 bits/símbolo) de un archivo de texto plano y su equivalente comprimido.

## Dependencias

Este ejercicio no requiere librerías externas. Utiliza únicamente la librería estándar de Python.

## Ejecución

El script debe ejecutarse estando ubicado dentro de la carpeta `ejercicio3`.

```bash
cd ejercicio3
python main.py
```

El programa utilizará los archivos `archivos/archivo.txt` y `archivos/archivo.zip` ya incluidos.
