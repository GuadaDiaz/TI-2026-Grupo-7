# Ejercicio 7 — Validador de CUIT/CUIL (Módulo 11)

Valida un CUIT/CUIL argentino de 11 dígitos aplicando el algoritmo de dígito verificador Módulo 11, mostrando el detalle del cálculo paso a paso.

## Dependencias

Este ejercicio no requiere librerías externas. Utiliza únicamente la librería estándar de Python.

## Ejecución

El programa es interactivo. Debe ejecutarse estando ubicado dentro de la carpeta `ejercicio7`.

```bash
cd ejercicio7
python validador_cuit.py
```

Al ejecutarse, el programa te pedirá que ingreses un CUIT o CUIL por teclado. Puedes ingresarlo con o sin guiones.
