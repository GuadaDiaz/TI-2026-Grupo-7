# Práctico de Máquina 2: Desafío de Proveedores de Compresión

La resolución completa está en [`solucion_propia/`](solucion_propia/):

- **Solución propia (Sorteo A):** Markov de orden 1 + Huffman estático por contexto, con formato propio `.tdi`.
- **Solución externa (Sorteo B):** PeaZip, formato PEA (PCOMPRESS2, equivalente a Deflate nivel 6).
- **Baseline de la cátedra:** `gzip -n -6`.

En [`solucion_propia/README.md`](solucion_propia/README.md) están la explicación del algoritmo, el formato `.tdi`, las instrucciones de uso, el benchmark y el análisis de resultados.
